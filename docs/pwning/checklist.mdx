Mapa dos tópicos de pwning que aparecem em CTFs. Serve como índice do que já existe no site e como lista do que ainda falta escrever.

- ✅ disponível (o nome é o link para a página)

Quer escrever um dos que faltam? Veja como contribuir no [repositório](https://github.com/AriiiAlves/CatchTheFox#contribuindo).

## Format Strings

| | Tópico | O que é |
|:-:|---|---|
| ✅ | [Format Strings](./stack/format-strings.md) | Leak com `%p`, leitura com `%s`, escrita com `%n` |

| ⬜ | Format string de um disparo | Uma única chamada: `.fini_array`, `__libc_atexit`, loop de volta para a `main` |

## ROP

| | Tópico | O que é |
|:-:|---|---|
| ✅ | [ROP](./stack/rop/index.mdx) | Encadear gadgets terminados em `ret`; tipos de gadget; ROP com syscall |
| ✅ | [ret2libc / ret2system](./stack/rop/ret2libc.mdx) | Leak com `puts(puts@got)` e `system("/bin/sh")` |
| ✅ | [Partial Overwrite](./stack/rop/partial-overwrite.mdx) | Trocar só os bytes baixos de um endereço para contornar PIE/ASLR |
| ✅ | [Stack Pivoting](./stack/rop/stack-pivoting.mdx) | Mover `rsp` para uma região controlada (`leave; ret`) |
| ✅ | [SIGROP (SROP)](./stack/rop/sigrop.mdx) | `sigreturn` com frame forjado para controlar todos os registradores |
| ⬜ | ret2csu | Gadgets de `__libc_csu_init` para controlar `rdx`/`rsi`/`edi` (glibc < 2.34) |
| ⬜ | ret2dlresolve | Forjar estruturas de relocação para o `ld.so` resolver `system` sem leak |
| ⬜ | ORW (open-read-write) | Chain ou shellcode para ler a flag quando `execve` é bloqueado por seccomp |
| ⬜ | ret2vdso / vsyscall | Gadgets em regiões mapeadas pelo kernel |
| ⬜ | JOP / COP | Encadear por `jmp`/`call` indiretos em vez de `ret` |
| ⬜ | BROP (Blind ROP) | ROP sem o binário, em servidores que fazem `fork` |
| ⬜ | `mprotect` + shellcode | ROP curto que torna uma região executável e pula para ela |

### Vulnerabilidades e primitivas

| | Tópico | O que é |
|:-:|---|---|
| ✅ | [Heap Overflow](./heap/heap-overflow.mdx) | Sobrescrever o chunk vizinho |
| ✅ | [Use-After-Free](./heap/uaf.mdx) | Ler/escrever/executar por um ponteiro já liberado |
| ✅ | [Double Free (fastbin dup)](./heap/double-free.mdx) | Mesmo chunk duas vezes na lista → `malloc` em endereço arbitrário |
| ✅ | [Unlink](./heap/unlink.mdx) | Escrita via `unlink` com chunk falso |
| ✅ | [Leak de libc pela unsorted bin](./heap/malloc-consolidate.mdx) | `fd`/`bk` apontando para a `main_arena`; `malloc_consolidate` |
| ⬜ | Off-by-one / poison null byte | 1 byte no `size` do vizinho → chunks sobrepostos |
| ⬜ | Overlapping chunks | Dois ponteiros válidos para a mesma memória a partir de `size` corrompido |
| ⬜ | Unsorted bin attack | Escrever um ponteiro da libc em endereço arbitrário (glibc < 2.29) |
| ⬜ | Largebin attack | Escrever um endereço da heap em local arbitrário via `bk_nextsize` |
| ⬜ | Tcache stashing unlink | Abusar da migração smallbin → tcache |
| ⬜ | Ataque à `tcache_perthread_struct` | Controlar contadores e cabeças de todos os bins |
| ⬜ | Chunks `mmap` | Corromper `size`/flag `M` de chunks grandes |

### Houses

| | Tópico | O que é |
|:-:|---|---|
| ✅ | [House of Prime](./heap/malloc-maleficarum/house-of-prime.mdx) | Dois `free` com `size` controlado trocam a arena por uma falsa (glibc 2.3.x, histórica) |
| ✅ | [House of Mind](./heap/malloc-maleficarum/house-of-mind.mdx) | Bit `A` no `size` → `free` usa arena forjada → escrita de um ponteiro da heap |
| ✅ | [House of Force](./heap/malloc-maleficarum/house-of-force.mdx) | `size` do top chunk gigante → `malloc` em qualquer endereço (glibc < 2.29) |
| ✅ | [House of Lore](./heap/malloc-maleficarum/house-of-lore.mdx) | Corromper o `bk` de um chunk na smallbin → `malloc` devolve chunk falso |
| ✅ | [House of Spirit](./heap/malloc-maleficarum/house-of-spirit.mdx) | `free` em chunk falso → o próximo `malloc` devolve região controlada |
| ⬜ | House of Einherjar | Off-by-null + `prev_size` falso → consolidação para trás e overlap |
| ⬜ | House of Orange | Sem `free`: encolher o top chunk para ele ir à unsorted bin; + FSOP |
| ⬜ | House of Botcake | Double free entre tcache e unsorted bin, contorna a tcache key |
| ⬜ | House of Rabbit | Chunk falso na fastbin + `malloc_consolidate` |
| ⬜ | House of Tangerine | House of Orange adaptado ao tcache (sem `free`) |
| ⬜ | House of Water | Controle do tcache sem leak |
| ⬜ | House of Muney | Corromper chunk `mmap` para remapear parte da libc e forjar símbolos |
