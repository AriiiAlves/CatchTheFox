Radare2 é um framework avançado de código aberto para análise de binários. Sua interface é via linha de comando. É uma alternativa ao gdb (e também a disassemblers como o Ghidra e o IDA, já que faz análise estática e dinâmica).

Instale com: `sudo apt-get install radare2`

(A versão dos repositórios do apt costuma ser bem antiga. O projeto recomenda instalar pelo [repositório oficial](https://github.com/radareorg/radare2): `git clone https://github.com/radareorg/radare2 && radare2/sys/install.sh`.)

## Conceitos básicos

### Abrindo um binário

```bash
# Modo básico
r2 /caminho/para/binario

# Modo write (permite modificações)
r2 -w /caminho/para/binario

# Com modo de depuração
r2 -d /caminho/para/binario
```

### Comandos

Dica: quase todo comando aceita `?` no final para mostrar a ajuda dele (ex: `a?`, `pd?`). Adicionar `j` no final costuma mostrar a saída em JSON, e `~` funciona como um grep (ex: `afl~main`).

Navegação:

- `?` - Ajuda geral
- `?*` - Lista todos os comandos
- `s main` - Vai (seek) para a função main
- `q` - Sair

Informação:

- `i` - Informações do binário
- `iI` - Informações detalhadas
- `iz` - Strings no binário
- `is` - Símbolos
- `il` - Bibliotecas

Modos de visualização:

- `V` - Entra no modo visual (use `p`/`P` para alternar entre as visualizações)
- `VV` - Modo de grafo (gráfico da função atual)
- `V!` - Modo visual com painéis

### Análise estática

Antes de tudo, rode `aaa` para analisar o binário. Sem isso, comandos como `afl` e `pdf` não vão encontrar as funções.

Desmontagem

- `pd` - Desmontar no endereço atual
- `pd 20` - Desmontar 20 instruções
- `pdf` - Desmontar função atual
- `pdf @ main` - Desmontar função main (o `@` executa o comando em outro endereço, sem mudar a posição atual)

Análise de funções

- `aaa` - Analisa todo o binário (funções, referências, etc.)
- `afl` - Listar todas as funções
- `afll` - Listar funções com detalhes
- `afvn` - Renomear variáveis locais (`afvn novo_nome nome_antigo`)

Análise de Strings

- `izz` - Extrair todas as Strings
- `izzj`  - Strings em formato JSON
- `/ flag` - Buscar a string "flag" na memória
- `izz~flag` - Filtrar as strings que contêm "flag"

Cross-references

- `ax` - Listar referências
- `axf` - Referências a partir do endereço atual (from)
- `axt @ sym.main` - Referências para main (to)

Análise de seções

- `iS` - Listar seções
- `iSj` - Seções em JSON

### Análise dinâmica

Iniciar depuração: `r2 -d ./binario`. Ou dentro do binário: `ood` (reabrir em modo depuração; aceita argumentos, como `ood arg1 arg2`). `doo` é um atalho para o mesmo comando.

Controle de execução

- `db` - Listar breakpoints
- `db 0x8048450` - Definir breakpoints
- `db -0x8048450` - Remover breakpoint
- `dc` - Continuar execução
- `dcu main` - Continuar até um endereço (ex: até a main)
- `ds` - Step (passo a passo, entrando em funções - step into)
- `dso` - Step over (executa função sem entrar nela)

Inspeção de memória

- `dm` - Mapa da memória
- `px 64` - Hexdump de 64 bytes
- `pxw 32` - Hexdump words
- `pxq 16` - Hexdump quads
- `psz 50` - Print string de 50 chars

Registradores

- `dr` - Mostrar Registradores
- `dr eax` - Mostrar valor de EAX
- `dr eax=0x10` - Definir EAX para 0x10
